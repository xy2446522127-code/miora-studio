花海画布插件开发规范

本文档帮助你快速构建符合规范、可安全运行的花海画布插件。

1. 目录结构

一个插件是一个独立文件夹，建议结构如下：

my-plugin/
├─ plugin.json       # 插件清单（必需）
├─ icon.png          # 插件图标（可选）
├─ README.md         # 插件说明（可选）
├─ backend/
│  └─ runner.py      # 本地任务入口
└─ assets/           # 资源文件（可选）

2. plugin.json

声明插件基本信息、运行时、媒体能力与最小权限。

{
  "id": "my-image-plugin",
  "name": "我的生图插件",
  "version": "1.0.0",
  "runtime": "python-external-plugin",
  "entry": "backend/runner.py",
  "mediaKinds": ["image"],
  "capabilities": ["image", "submitTask", "pollTask", "fetchArtifacts"]
}

3. 能力声明

智能画布只会列出与当前图片或视频任务相匹配的插件。

4. 配置表单

敏感凭据只保存在本机 data/local/，不得写入插件源码。

5. 任务生命周期

任务需覆盖创建、运行、进度更新、完成、失败和取消。

6. 本地存储与安全

网络地址必须声明白名单；文件访问限制在授权目录。

7. 自检与调试

安装前运行结构、入口、能力、权限和版本兼容检查。
