# 花海画布：批量连线与固定项目排序实施方案

## 目标

1. 普通画布和智能画布共用同一套“多选代理端口”交互，一次拖线可创建多条真实连接。
2. 代理端口只属于当前选择状态，不创建永久分组节点，不改变已有节点数据结构。
3. 项目管理改为按更新时间固定排序的响应式网格，禁用卡片拖动，保留与卡片严格对齐的水面倒影。

## 一、批量选择代理端口

### 1. 选中状态

- 保留框选、`Shift/Ctrl + 单击`追加或移除选择。
- 两个及以上节点被选中后，绘制统一的选区边界。
- 边界顶部显示“已选择 N 个节点”，右侧检查器显示：
  - 总节点数；
  - 可输出节点数；
  - 当前悬停目标的可连接数；
  - 冲突数及原因。
- 选区边界靠近目标的一侧显示一个代理输出端口；端口带分支图标和数量徽标。
- 代理端口是临时 UI，不写入 `nodes`，取消选择后立即消失。

### 2. 拖线与目标反馈

- 从代理端口开始拖动时，内部节点到代理端口显示低亮汇聚细线。
- 目标端口按兼容结果显示三种状态：
  - 青色：全部来源可连接；
  - 琥珀色：只有部分来源可连接；
  - 红色：没有来源可连接。
- 拖线过程中不创建数据；松开鼠标后才提交。
- `Esc`、右键、切换工具或开始画布平移时取消临时连接。

### 3. 兼容性规则

每个来源节点逐一复用现有 `canConnect`、端口类型和循环检测规则：

- 排除没有输出能力的节点；
- 排除来源与目标相同的自连接；
- 排除已有的重复连接；
- 遵守目标端口的类型与最大输入数量；
- 循环是否合法继续服从现有节点类型规则，不另造一套判断；
- 工作流正在级联运行时禁止修改连接，避免运行中的图结构发生变化。

混合类型选择不会被静默跳过。若只兼容部分节点，松开后显示轻量确认层：

- “连接全部”仅在全部兼容时可用；
- “仅连接兼容的 N 个”明确列出被跳过的节点；
- 若目标是单输入端口，可选择“插入集合节点”，且该节点必须真实可见、可撤销，禁止暗中聚合。

### 4. 提交、撤销和可视化

- 一次批量连接作为一个事务写入多条普通 `connections`。
- 每条连接保持原有 `from`、`to`、`kind` 字段；仅增加可选 `batch_id`，旧版本忽略该字段也能读取。
- 一次 `Ctrl+Z` 删除整批新连接；一次重做恢复整批连接。
- 提交成功显示“已建立 N 条连接”，失败不留下半成品。
- 选择仍存在时，连线以共享主干和 `×N` 徽标呈现；取消选择后恢复为真实连线，路径接近时可继续视觉合束，悬停后展开。
- 沿用现有稀疏输液式流光：普通批量线低亮，选中来源或目标时整束增强；低动态模式关闭流动。

## 二、两个画布模式同步

### 共享核心

新增一个无 DOM 依赖的批量连接核心模块，统一提供：

- `collectBatchSources`
- `validateBatchConnections`
- `commitBatchConnections`
- `describeBatchConflicts`

普通画布与智能画布仅负责各自的选区边界、代理端口位置和面板渲染，连接校验与提交逻辑不得复制两份。

### 普通画布

- 复用现有 `selected` 集合和框选逻辑。
- 将当前会创建永久 `group/promptGroup` 的批量连接路径改为代理端口事务。
- 明确的“分组”按钮继续保留；只有用户点击“分组”才创建真实分组节点。
- 检查器显示复制、分组、对齐和连接兼容性。

### 智能画布

- 复用现有 `selectedIds`、撤销快照和连接渲染层。
- 使用相同代理端口与事务，不引入第二种连接数据。
- 不新增“智能建议”侧栏，也不以建议面板占用画布空间。
- 兼容性结果直接显示在代理端口、目标端口和短时状态提示中。
- 已有智能分组、级联运行、历史连接和连接合束逻辑保持不变。

### 两种画布的同步边界

以下属于通用画布能力，必须同时接入普通画布和智能画布：

- 深海毛玻璃设计令牌与无倒影创作背景；
- 鼠标跟随光、点击波纹和低动态模式；
- 明确的缩放百分比与 `Ctrl + 滚轮` 缩放反馈；
- 输出图片、视频节点按媒体比例自适应；
- 右侧生成成果入口、分类、复制、拖拽、入库和定位文件；
- 视频生成的 API 与本地插件来源；
- 稀疏输液式流光、选中关系线高亮和连接合束；
- 多选代理端口、兼容性校验、批量连接和事务撤销。

模式专属功能可以不同，但不得用两套实现重复通用能力：

- 普通画布保留节点检查器、原有节点类型和级联运行入口；
- 智能画布保留智能分组、智能生成、历史关系和专属布局能力；
- 智能画布不显示独立“智能建议”侧栏。

## 三、项目管理固定时间网格

### 排序

- 默认顺序：最新在左上，向右排列，换行后继续向下。
- 主排序：`updated_at` 降序。
- 次排序：`created_at` 降序。
- 最终稳定排序：`id`，避免相同时间时页面刷新后跳位。
- 新建画布或编辑画布后，按时间自动回到正确位置。

### 布局与操作

- 移除卡片拖动监听、自由坐标布局和卡片位置持久化写入。
- 已有 `board_x/board_y` 数据保留但不读取，避免破坏旧数据或未来回退。
- 项目区域改为正常文档流和 CSS Grid：
  - `≥ 1440px`：4 列；
  - `1100–1439px`：3 列；
  - `760–1099px`：2 列；
  - `< 760px`：1 列。
- 页面使用常规滚动，不再通过拖动画布寻找项目。
- 悬停卡片不放大、不位移；只提升玻璃清晰度、描边亮度，并在预留的底部操作区显示按钮。
- 原“整理视图”按钮替换为带锁的排序状态“更新时间：新 → 旧”。

### 倒影

- 每张卡片生成一个 `aria-hidden`、`inert` 的视觉副本作为倒影，绝不复制可点击和可聚焦行为。
- 倒影与原卡片使用同一网格列，垂直翻转，透明度约 `0.10–0.16`。
- 使用渐隐遮罩、轻微模糊和低频横向波动；倒影高度不超过卡片的 38%。
- 倒影层 `pointer-events:none`，不参与布局高度计算，不遮挡下一行卡片。
- `prefers-reduced-motion` 下停止水波动画，保留静态渐隐倒影。

## 四、验证

- 两种画布分别覆盖：框选、追加选择、取消选择、全兼容、部分兼容、完全不兼容、重复边、循环、单输入目标、撤销与重做。
- 验证批量操作后仍是普通连接，保存、重载、导入导出与旧画布数据兼容。
- 验证智能画布的分组、级联运行和历史线不受影响。
- 验证项目卡片不能被拖动，刷新后排序稳定，新建或编辑后位置正确。
- 在 `1920×1080`、`1440×900`、`1280×720` 和窄屏验证网格列数、操作区与倒影无重叠。
- 以本目录三张效果图作为视觉基准，实施后生成同视口截图并逐张对照。

## 五、实施顺序

1. 抽取共享批量连接校验与事务模块。
2. 普通画布接入代理端口并删除“批量连接自动建组”的旧路径。
3. 智能画布接入同一核心，补齐智能建议与连接合束。
4. 项目管理切换固定排序网格并移除拖动行为。
5. 加入倒影、响应式与低动态模式。
6. 完成功能回归、视觉对照和测试后再提交。
