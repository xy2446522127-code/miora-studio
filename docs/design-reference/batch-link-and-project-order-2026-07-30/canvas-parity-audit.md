# 普通画布与智能画布功能同步审查

审查日期：2026-07-30

## 结论

本轮要求的通用画布能力已经同步到普通画布与智能画布。两种模式仍保留各自的节点类型、运行流程和专用设置，但共用交互规则一致。智能画布不增加“智能建议”侧栏。

## 同步结果

| 通用能力 | 普通画布 | 智能画布 | 统一规则 |
| --- | --- | --- | --- |
| 多节点框选 | 已实现 | 已实现 | 框选后显示统一批量边框与数量 |
| 临时批量代理端口 | 已实现 | 已实现 | 一个代理端口代表本次所选节点，不创建永久分组 |
| 一拖多连 | 已实现 | 已实现 | 一次拖动原子创建多条真实连线，并作为一次撤销记录 |
| 部分兼容提示 | 已实现 | 已实现 | 不自动连接，用户明确选择“仅连接兼容项”后才提交 |
| 媒体节点按比例自适应 | 已实现 | 已实现 | 图片、视频按素材宽高比决定预览节点尺寸 |
| 右侧生成成果入口 | 已实现 | 已实现 | 全部、图片、视频、任务分类；支持拖放、复制、素材库和定位 |
| 视频插件来源 | 已实现 | 已实现 | API 与已发现的视频插件统一出现在来源选择中 |
| 稀疏输液式流光 | 已实现 | 已实现 | 普通连线低密度流动，选中关联线提高亮度与速度 |
| 生成文件定位 | 已实现 | 已实现 | 成果列表可定位具体文件或打开生成目录 |
| 画布缩放百分比 | 已实现 | 已实现 | 画布区域 Ctrl + 滚轮缩放并显示百分比 |
| 鼠标光效与低动态模式 | 已实现 | 已实现 | 空白画布不产生点击波纹，拖拽/连线时禁用，支持 reduced-motion |
| 创作区倒影 | 已关闭 | 已关闭 | 只有首页与项目管理保留克制倒影 |

## 模式专属能力

- 普通画布继续使用原项目的完整节点工具栏、节点内参数、检查器、工作流和级联运行。
- 智能画布继续使用智能提示词、智能分组、素材提及、日志与智能级联等专属流程。
- “智能建议”不属于智能画布的交付范围，页面中不渲染该标题、面板或入口。

## 验收规则

1. 每项通用能力必须同时具备普通画布和智能画布的静态检查或交互检查。
2. 批量连接不能隐式跳过冲突节点。
3. 缺少任一画布模式的实际截图或验证记录，该通用能力不得标记完成。
4. 保留原项目 API、画布数据、工作流与插件协议，不因视觉调整修改数据结构。
