# MIORA Studio UI previews

This directory contains both the visual direction and verified screenshots of
the running application.

- `miora-studio-canvas-concept.png` — generated 16:9 high-fidelity art direction.
- `studio-home.png` — live main studio shell at 1920×1080.
- `project-manager.png` — live project and canvas manager at 1920×1080.
- `canvas-editor.png` — live infinite-canvas editor at 1920×1080.

## Concept prompt

The concept was generated with the built-in image generation tool using the
`ui-mockup` workflow. The prompt specified a professional graphite workspace,
cyan-to-violet accents, a compact node rail, connected workflow nodes, a right
asset/inspector panel, and the exact product name `MIORA STUDIO`.

The checked-in application screenshots are the source of truth for the shipped
interface; the generated concept is retained as design rationale.
