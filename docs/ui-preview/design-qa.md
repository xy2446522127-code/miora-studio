## 已验证

- 花海书法 Logo、品牌标题、深海背景、青色描边、毛玻璃与珊瑚橙主操作保持一致。
- 首页与项目管理保留克制的水面残影；无限画布和智能画布未出现倒影或镜面地面。
- 无限画布在桌面端具备左侧工具栏、顶部命令区、右侧检查器和右下导航图；窄屏自动隐藏检查器，节点内部字段仍可操作。
- 项目卡片在桌面和窄屏均能回到可视中心；720px 窄屏隐藏项目侧栏并保留新建、刷新和视图操作。
- API 设置默认深色主题，智能画布顶部命令控件不再回落为浅色。
- 跟随光层使用单实例和 `requestAnimationFrame`；普通移动不生成波纹。
- 只有可操作元素单击生成短波纹；普通元素两圈，项目卡片三圈；空白画布、拖拽、平移、缩放和调整大小期间不生成波纹。
- `prefers-reduced-motion` 关闭跟随动画与点击波纹，仅保留静态焦点和悬停反馈。
- 参考稿中的项目数量和节点内容属于示例数据；实机截图使用本地真实数据，因此数量和文案不同，不视为布局缺陷。
